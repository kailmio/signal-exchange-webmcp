# Mission Deck — 60 Second Product Demo

Agent actions are powerful. But on most websites, they disappear behind the chat.

Mission Deck makes every action visible. Through Web M C P, an agent reads the real board, discovers three powers, and recommends the one that fits the moment.

Forge turns one rough idea into concrete actions. Before anything changes, you see the exact proposal. The agent can’t swap it later. Only the preview you approve can be committed.

Focus chooses the highest-leverage next move.

Then there’s Wild. It delivers a bounded surprise—memorable, but still compatible with the board. Even the surprise stops for approval.

Every Web M C P preview and commit appears in the shared activity rail. Refresh keeps committed work. Replayed or stale actions are rejected. And Undo restores the prior board in one move.

No hidden automation. No mystery state.

Just a person and an agent, acting on the same web page—with the human visibly in control.
