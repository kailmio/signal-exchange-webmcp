# Signal Exchange Narration

Your agent can research the web. But can it safely acquire the data it needs?

This is Signal Exchange. A WebMCP marketplace for agent-ready data, with the person's goal, budget, and consent built into the page.

Here, a retailer needs fresh Sydney foot traffic for a weekend pop-up. The agent inspects the live exchange, searches within forty credits, and compares trust, freshness, formats, and price. MetroPulse is the strongest fit.

The agent bids twenty credits for seven days. The seller counters at twenty-two. This is only a preview: the wallet is still one hundred, and access is still locked.

After the person approves, WebMCP commits that exact visible deal. The wallet becomes seventy-eight, and the machine-ready schema unlocks. Every step is attributed in Activity.

Undo restores the credits and removes access.

Agents operate the marketplace. People keep intent, limits, and consent.
