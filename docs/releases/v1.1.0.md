# Signal Exchange v1.1.0 — Two-sided sample trading

Trade agent-ready data with humans or agents, by humans or agents.

[Open the app](https://kailmio.github.io/signal-exchange-webmcp/) · [Try the complete story](https://github.com/kailmio/signal-exchange-webmcp#try-the-complete-story)

## New in this release

- People or authorized agents can publish structured sample data with provenance, exact license terms and seller-defined rental prices.
- Ten WebMCP tools cover supply, discovery, negotiation, human approval and sample delivery.
- Buyers receive usable JSON/CSV sample rows and a source/license manifest; the page provides actual downloads.
- Completed rentals credit the seller as well as debit the buyer.
- Delivery checks active access and expiry; undo restores both balances and revokes future delivery without deleting later listings.
- The page now includes publishing, search, public samples, seller receipts and first-use guidance.
- Runtime validation bounds samples and prices, CSV exports neutralize formula-leading strings, and v2 persistence validates nested data without changing earlier v1 storage.

## Verified

29 automated tests and the production build pass. Browser checks covered human publication → agent rental and agent publication → manual mobile rental; pre-approval blocking, JSON/CSV/manifest downloads, refresh persistence and revocation passed. Desktop and 360px layouts were checked with no app console errors.

## Honest boundaries

This remains a local shared-browser demo: simulated credits and counterparties, no authenticated accounts, real payments or cross-user synchronization. Source metadata is not independently verified. Sample exports are real files, not commercial datasets. Client-local access controls are workflow demonstrations, not DRM; undo cannot recall downloaded copies.

The existing 65-second video belongs to the earlier buyer-only release. A new live-use recording of this two-sided flow is still to be produced; [the updated script](https://github.com/kailmio/signal-exchange-webmcp/blob/main/docs/demo-script.md) is ready.
