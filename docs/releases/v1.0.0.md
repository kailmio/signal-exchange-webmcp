# Signal Exchange v1.0.0

A self-contained WebMCP data marketplace demo: agents find, compare, and negotiate data rentals while people control the budget, approve the exact deal, and can undo the result.

## Try it

- [Live Signal Exchange app](https://kailmio.github.io/signal-exchange-webmcp/)
- [65-second walkthrough](https://kailmio.github.io/signal-exchange-webmcp/video/signal-exchange-walkthrough.mp4)
- [Agent prompts and manual demo instructions](https://github.com/kailmio/signal-exchange-webmcp#65-second-demo)

## What works

- Seven page-defined WebMCP tools share the app's typed command layer.
- Search and compare three Sydney foot-traffic offers against a 40-credit budget.
- Preview a seven-day rental with an exact seller counteroffer: bid 20, counter 22.
- Require the person's visible approval before committing the active proposal.
- Enforce expiring, revision-bound, one-time proposal tokens; reject unapproved or stale commits.
- Update the wallet from 100 to 78 and unlock schema access; undo restores credits and revokes access.
- Support manual controls when browser WebMCP is unavailable.

## Scope and verification

Sellers, credits, negotiation, and access are deterministic local simulation. No real payments, seller communication, or dataset delivery are claimed. The current video is a text-led walkthrough, not a recording of a live agent session.

The release workflow runs 15 automated tests, the TypeScript/Vite production build, and the 65-second HyperFrames video render before GitHub Pages deployment. The prior public deployment passed browser tool discovery and the complete approval/commit/undo smoke test.

This is the first Signal Exchange release. Earlier v0.x releases are preserved as superseded pre-pivot prototypes, not the current product.
