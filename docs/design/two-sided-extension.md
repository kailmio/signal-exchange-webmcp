# Two-sided extension

Preserve the accepted Signal Exchange concept: midnight background, brass dividers, cyan metadata, serif display headings, horizontal offer rows and an approval sidebar. No rebrand or new imagery is needed; extend existing panel, button and form styles.

Approved product copy: “Trade agent-ready data. Human or agent, either side.” Supporting copy explains publishing, inspecting samples, negotiating and exact approval. A persistent note states that this is a shared-browser simulation, not a multi-user marketplace.

New surfaces: an inline Publish data panel with seller, title, description, coverage, source, license, list/minimum price and a bounded JSON sample editor; a search bar; an offer details panel showing provenance, license, a public sample and publisher attribution; a post-approval data delivery panel with JSON/CSV downloads and a seller credit receipt.

The seeded publishing example is synthetic Sydney weekend foot-traffic data. Publish is an explicit submit action with rights acknowledgement. Agents receive the same capabilities through typed tools; browser-local storage is not a security boundary and all data is demonstrative.

The primary flow is publish → search exact listing → inspect public sample → bid → review exact license/counteroffer → approve → commit → receive sample bundle → undo. On mobile all fields, code samples and actions remain within the viewport.
